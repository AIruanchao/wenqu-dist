# 项目宪法模板（wenqu v3.4 复用资产）

> 用法：复制到项目仓 memory/constitution.md，按三要素逐条填实。条款**收编项目已活铁律**（有实战出处的才入宪），禁止凭空新造。血统法=四轨出生制产物模板。

## 治理节（必填）
- **批准/修订日期**+**SEMVER**：MAJOR=删/重定义不可协商条款；MINOR=新增或实质扩展；PATCH=非语义措辞。
- **修订程序**：仅项目拍板人（或授权人）发起修订；合并前 AI 全文比对与代码门冲突；AI 无权自行修改。
- **违反登记**：被迫违反须记入当批 spec 的「违反登记」段（违反项/为何需要/被拒的更简方案），无书面理由即不合规。

## 条目三要素格式（每条照此）
```markdown
## 第 N 条 · <简短名称>【不可协商】
- 规则：<可判定的禁止/要求>
- 理由：<为什么不能妥协>
- 出处：<实战轮号/PIT 编号/战训册节——必须真实可回源>
```

## 推荐起步条款域（按需取用，均须带出处）
完成语义｜收敛纪律（N 轮异源+工件落账）｜实现/验证分离（禁自证）｜生产写口令｜mock 不掩盖契约断链｜fail-closed｜口径唯一（语义变更三件套）｜基线只进不退｜账本留痕｜战训闭环｜守护文件原命令重算｜事故回流规格。

## 维护纪律
- 季度合规复审；宪法 lint 不做硬门（meta 级条款机器判定必空转——12 交叉审实证）。
- 与域规格（sdd/specs/）联动：域不变量违反=违反宪法「口径唯一/事故回流」族。
