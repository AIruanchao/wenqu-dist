# 咖机汇 ERP 快速入门指南

## 首次使用
1. 打开浏览器访问 erp.nenie.vip
2. 用管理员提供的账号密码登录
3. 首页展示：今日销售额、库存总值、待办事项

## 日常操作

### 销售开单
1. 左侧菜单 → 销售 → 新建销售单
2. 选择客户（可搜索或跳过=匿名购买）
3. 添加商品（扫描 SN 或搜索 SKU）
4. 确认金额 → 收款（现金/微信/支付宝/储值/积分）
5. 单据状态变为「已收款」

### 采购入库
1. 左侧菜单 → 进货 → 新建采购单
2. 选择供应商、添加商品和数量
3. 确认采购单 → 到货后入库
4. 库存自动增加

### 库存查询
1. 左侧菜单 → 库存
2. 查看各门店库存余量
3. 可按 SKU、门店、状态筛选

### 退货处理
1. 左侧菜单 → 销售 → 销售退货
2. 选择原销售单 → 选择退货商品
3. 确认退款 → 库存自动恢复

## 常见问题

**Q: 提示"请选择门店"怎么办？**
A: 这是系统在确认您管理哪家门店。如果您只管理一家，系统会自动选择。如果提示持续出现，请联系管理员。

**Q: 收款后单据显示"未收款"？**
A: 刷新页面或等待几秒。系统有自动同步机制。如果持续异常，系统会自动检测并修复。

**Q: 忘记密码？**
A: 联系管理员重置。
