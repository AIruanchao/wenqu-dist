# 问渠轨道规范（发行版 v1.0.15）

> 血统：maccc `bug-scan-pipeline` skill v1.8 的仓中立模板（剥离 ERP 执行件指针，站点定义参数化）。
> 配套执行器：`../cli/wenqu`（v0.3.0-fork15-maccc；fork1-15 修复全带源码注释，CHANGELOG=完整修复史）+ `../probes/stations.json`（三域探测器 v6）。
> 适用：任何要系统性找 bug 的仓——新项目从第一行代码起、存量仓从第一次委托扫描起。

## 0. 定位与铁律（违反任何一条=本轮扫描无效）

本规范是**编排层**：不造扫描工具，只定义站位、档位、账本与收敛协议。智能在会话侧（agent 读本规范做判断与编排），机械件在 CLI/探测器侧。

1. **范围大小与验证强度分开选，禁止「增量=低风险」**——涉权限/资金/租户/迁移/公共基础层，至少 STANDARD，权限资金类 INCIDENT。
2. 执行状态五态 PASS/FAIL/BLOCKED/ERROR/SKIP；**只有 PASS 算通过**；超时/空输出/工具缺失不得记零发现；站内任一件 BLOCKED/ERROR→该站整站不得记 PASS。
3. **带有效豁免只能称「条件放行」，不能称「清零」**。
4. 站点断言依赖**有效证据集**而非固定前序站；证据时效双上限=权限/漏洞类 ≤7 天、其余 ≤30 天；指纹变化即失效重跑受影响站。
5. 收敛声明只走递归清零：N 轮异源（FAST=1/STANDARD=2/INCIDENT=3），同源重复不计轮，每轮落工件。

## 1. 八站骨架（站序=成本×确定性递增；每站=通用判据+执行件插槽）

| 站 | 名 | 执行件插槽（按仓配置） | 通过判据 |
|---|---|---|---|
| 0 | 范围冻结 | `wenqu init`（sha256 范围哈希入 state.json）；commit SHA/环境/定级理由为**会话侧职责**——记入账本 note 或 rounds 工件（CLI 不落这些字段） | 范围分母齐全+身份一致（commit SHA/环境/范围哈希三源由会话侧核） |
| 1 | 源闸 | 仓的 CI 快速门（lint/typecheck/unit/守卫棘轮） | 全绿+棘轮不升 |
| 2 | 静态与供应链 | `wenqu run <station>`（内置 py-static/sh-static/tests/supply + stations.json 域探测器）；克隆检测；CVE 审计 | 克隆≤基线；CVE 零 HIGH+；探测器 FAIL 自动落账 |
| 3 | 契约与数据 | API 契约对账/权限矩阵/schema 漂移（按栈选件） | 无未归属端点；负例全拦+正例全通；漂移白名单制 |
| 4 | 行为面 | e2e 套件+浏览器抽检 | 全绿+每测试点有已看证据 |
| 5 | 实弹面 | 真实业务流全链操作（生产写须所有者明确口令） | 状态断言全 PASS+数据回基线 |
| 6 | 对抗面 | `wenqu charter` 发射反方评审（异构端点优先）+`ingest` 回收产物。⚠上游 charter 模板内嵌 `wsl.exe` 探测命令（WSL 环境定制）——跨平台使用时须改该行为本机等价只读探测 | 每轴必问全覆盖；**零发现结论必须出自 ≥2 独立上下文**（二审定律：首审系统性漏 30-40%） |
| 7 | 运行时 | 常驻哨兵/探针/告警链（不参与收敛声明，事件回流站6） | 哨兵活着且真的会叫 |

**档位×站点矩阵**：PR 档=0+1；周档=0+2+3；nightly=0+4；版本/首版=0+5；事件=0+6；季度=全线+演练。升档只增不减。小型仓可合并站（如 2+3 并跑），但站 0 与收敛环不可省。

## 2. 账本协议（`wenqu` 已实现）

- append-only jsonl：发现与状态转移都是追加行，永不改写历史（唯一例外=`wenqu repair` 按隔离规则重写坏行，隔离件留痕 .quarantine 可审计）；`findings` 按最新转移解析现态。
- 每条发现绑定：id（任意非空字符串——沿用各仓自己的编号习惯；AUTO id 由 CLI 自动生成）/sev(HIGH|MEDIUM|LOW)/status(OPEN→FIXING→FIXED→VERIFIED→CLOSED|PARTIAL)/location/evidence/fix/来源轮次。
- 状态流转经 `wenqu close <id> --to <状态> --note <理由>`；`sweep` 自动关（站位 PASS→其 AUTO 发现转 FIXED）。
- 外部产物（AI 站/人工审）经 `wenqu ingest <file.jsonl>`——原子全有或全无，方言自动归一（severity→sev、高/中/低→枚举）。

## 3. 收敛环与声明模板

- 修复即新攻击面：**任何成批修复后必须开对抗复扫循环**，曲线应递减（20→12→4→1→0 实战形态）；不递减=修复方法有系统病，停手复盘。
- 封环三条件：末轮零新发现+存量数据尾巴核查清+修复语义亲审零疑问。
- `wenqu verify --convergence N` +`--allow-open <限额>` 为机器门；清零声明须附盲区清单。**机器门（v1.0.2 fork2 已修 BSF-20261002-38）**：Converged 判定三前置=账本已标轮次 ≥N+轮号连续+近 N 轮零新发现，任一不满足即拒绝（「证据不足/不连续/未收敛」）；轮次证据两个来源=`run --round N`（AUTO 落账携带）与 `ingest --round N`。上游 v0.3.0 仍有空转缺陷——用上游正源时须会话侧兜底此判定。

**清零声明**（零豁免时）：在 SHA ___／环境 ___／范围哈希 ___／规则版本 ___ 内，完成 ___ 档验证：连续 N 轮零新发现、零未关闭项、零有效豁免。未覆盖项：___。
**条件放行**（有豁免时只能用此版）：同上限定+「除已列豁免 ___ 条（编号/理由/批准人/到期日）外零未关闭项；本声明=条件放行非清零」。

## 4. 域探测器规约（战训→探测器的自增殖机制）

- 协议：`<home>/stations.json` = `{"名字":{"cmd":[argv…],"sev":"…"}}`；cmd 在目标仓根执行（argv 直执行，管道用 `["bash","-c","…"]` 包裹）。**rc 契约（fork11 正源）**：探测器 exit 1=命中自动落账 OPEN（CLI exit 1）；exit ≥2=环境错误不落账不计通过（CLI die exit 2）；GNU xargs 123 归一为 1。
- **验证纪律（S7/S8 定谳入册）**：任何防线/修复的验证必须含双类故障注入——①目标仓内容异常（GBK/BOM/二进制/超长行）②宿主资源异常（磁盘满/只读/PATH 残缺/mktemp 失败）；修复须随 acceptance 夹具固化；夹具须过变异测试（还原坏形态必红）。
- **探测器已知盲区（v1.0.15 记录）**：BOM 贴目标行/CR-only 行尾/单行分号连写/`cmd && trap` 前缀连写——形态漏检，接入方知悉。
- **每轮扫描的新战训都是候选探测器**：一次窝工模式 → 固化成一条零依赖 grep/awk 命令 → 挂插座 → 以后每轮免费复扫。
- 初始三件（2026-10-02 F4 战训固化，已实测三站全中真缺陷）：`trap-double`（同文件双 trap EXIT 后写覆盖前写）/`guard-comment-swallow`（‖FAIL 被注释吞=防线假活）/`cred-cli-expose`（docker exec -e 传密码进进程列表）。
- 新仓接入节奏：首轮全量扫（S1 亲审+S2 异源对抗，HIGH 逐条亲验）→ 战训固化探测器 → 次轮起机械面免费、火力集中语义层。

## 5. 跨仓/只读委托 SOP

只读快照拉本机（勿在对方环境跑）→ 站0 指纹（对方 git SHA+范围哈希）→ 两轮异源 → HIGH 亲验 → 存疑项实机只读验证 → findings.jsonl 按 ingest 格式交付（含修法与来源轮次）→ 活事故置顶+处置权留对方 → **声明如实分列未覆盖站**（只读委托通常无站 4/5/7——离线审计≠运行态验证）。
用 `--home` 指向自己目录=对他人仓零写入。

## 6. 通道与豁免纪律

- 异源端点（多模型评审）探测沿用窗 7 天；宕机降级须登记豁免，**恢复后对降级轮补一次异源审**。
- 豁免台账五要素：触发条件/影响范围/决策人/解除条件/到期日；30 天日落失效；活跃豁免超 5 条熔断上报。
- 「扫干净」=限定范围收敛声明，非零 Bug 承诺；最高标准=可证伪、可审计、不把未知说成安全。

## 7. 盲区声明框架（每仓接入时填第一版，季度复盘）

接入仓时按此框架填本仓盲区（通用起点）：业务正确性只到已建模断言／schema 对账只对当前 schema／第三方行为不在视野／AI 生成语义 bug 静态结构性盲／性能只到基线快照／多模型交叉≠保证独立／**同族半改**（同一防线 A 处修了 B 处没修——对抗审必查族覆盖对称性，修复按 family 收口勿逐点）。
